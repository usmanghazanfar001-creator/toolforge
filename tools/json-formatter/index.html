About the JSON Formatter

JSON is the standard format for APIs and config files, but a single missing comma can break a whole payload. This JSON formatter parses your input, pretty-prints it with clean indentation, or compresses it into a single line, and tells you the exact reason when the JSON is invalid. Everything is processed locally in your browser, so API responses, tokens and customer data never leave your device.

When to use it

  • Debugging an API response that arrives as one unreadable line.
  • Validating a config file (package.json, tsconfig, settings) before you commit it.
  • Minifying JSON to shrink payload size for a request or a test fixture.
💡 Pro tip

Most JSON errors are trailing commas, single quotes instead of double quotes, or unquoted keys. JSON requires double quotes around every key and string.

Frequently asked questions

What is the difference between format and minify?

Formatting adds line breaks and indentation so people can read the data. Minifying removes all unnecessary whitespace so the data is as small as possible. Both produce identical data.

Why does my JSON say it is invalid?

The usual causes are a trailing comma, single quotes, an unquoted key, a missing bracket, or a comment. JSON does not allow comments or trailing commas, unlike JavaScript objects.

Is it safe to paste private JSON here?

Yes. Parsing happens in your browser and the text is not sent to any server or stored.
