About the Password Generator

Weak and reused passwords are the most common way accounts get compromised. This generator builds random passwords from the character sets you choose, using the browser's cryptographically secure random number generator (crypto.getRandomValues) rather than the predictable Math.random. It also estimates the entropy in bits so you can see how strong the result really is. Passwords are created on your device and are never transmitted or stored.

When to use it

  • Creating a unique password for every new account in a password manager.
  • Generating a Wi-Fi key or shared secret that is hard to guess.
  • Producing a temporary password for a new team member to change on first login.
💡 Pro tip

Length matters more than complexity. A random 16-character password with mixed character types is far stronger than an 8-character one with symbols. Use the no look-alikes option if you will type it by hand.

Frequently asked questions

How long should a strong password be?

At least 14 to 16 characters for important accounts. Longer is better, and every extra character multiplies the work an attacker needs.

What does entropy in bits mean?

It measures unpredictability. Each extra bit doubles the number of guesses needed. Above roughly 80 bits is considered strong for most uses.

Are the passwords saved anywhere?

No. They exist only in your browser tab. Copy the password into a password manager, because we cannot recover it for you.
