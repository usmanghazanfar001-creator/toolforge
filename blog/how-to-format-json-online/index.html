How to Format JSON Online

By ToolForge AI · 2026-09-28 · 2 min read

JSON (JavaScript Object Notation) is the standard format for sending data between apps and APIs. Minified JSON is compact but hard to read, so developers format it with indentation.

Format JSON in three steps

  1. Open the JSON Formatter and paste your JSON.
  2. Click Format to indent it, or Minify to shrink it.
  3. Copy the result.

Common JSON errors

  • Single quotes: JSON requires double quotes around keys and strings.
  • Trailing commas: {"a":1,} is invalid.
  • Unquoted keys: {a:1} must be {"a":1}.

Example
